PERSONAL ASSISTANT / LOCAL PROCESSING

Personal context.
Under its owner's control.

AMARA Local is a privately operated desktop assistant for conversation, personal knowledge and continuity across projects and everyday work.

This page identifies the application used in its Google authorization flow. It is not a public hosted assistant, a sign-up service or a repository of personal information.

What the application does

  • Processes conversation, speech and optional visual input using models running on the owner's computer.
  • Builds a local, searchable personal history from selected conversations, readable files and enabled activity awareness.
  • Can read an explicitly connected Gmail mailbox for personal assistance, summaries and notifications. It does not send email.
  • Can create encrypted personal-history archives in Google Drive. Encryption happens on the computer before upload.

Google permissions

Gmail uses read-only access. The separate Drive connection uses the drive.file permission to manage the backup files and folder created by AMARA. Google account authorization can be revoked in the account's security settings.

Personal records, webcam images, biometric enrollment and Google credentials are not published on this website.

Read the privacy policy for what is accessed, retained and shared, and the use information and terms for the scope of this private application.
