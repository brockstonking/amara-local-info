PRIVACY POLICY · 27 OCTOBER 2026

How AMARA Local handles information.

AMARA Local is a private desktop application operated by its owner for personal and household use. This policy describes the implemented personal-assistant features, including Google integration.

Information accessed

  • Conversation and work: enabled conversations, personal facts, readable file excerpts, source locations and foreground application context.
  • Visual input: screen or webcam images when those features are enabled. Named face enrollment is a separate, explicit local setup action.
  • Gmail: message metadata and content through an authorized read-only connection, used for inbox assistance, local context, summaries and notifications. AMARA does not send Gmail messages.
  • Google Drive: backup archives and their folder created by AMARA through its separate drive.file connection.

Local use and storage

Language, speech, visual understanding and face matching run on the owner's computer. Personal history, source excerpts, summaries, named profiles and explicitly enrolled face embeddings are stored locally. Camera and screen frames are transient; short descriptions may be retained when awareness features are enabled. Original camera images are not saved by those features.

Google user data supports the personal-assistant features described here. It is not sold, used for advertising, supplied to data brokers, or used to train general-purpose AI models. The application uses local inference and retrieval rather than training model weights on mailbox content.

The working knowledge database uses normal Windows file protection; it is not separately encrypted by AMARA. The archive encryption described below applies to backups.

Information transferred

Enabled Gmail and Drive connections communicate with Google's APIs. For Drive backup, the retained personal history, named profiles and face enrollment, and active voice reference are encrypted locally with AES-256-GCM before upload. Drive receives encrypted archives, not the recovery key. OAuth credentials, model weights and original disk files are excluded from those archives.

Internet research and user-approved browser actions can communicate with the selected websites. This information website does not host the desktop application's personal database, credentials, webcam feed or backup key.

Credentials and access

Google authorization is completed through Google's normal sign-in flow. The application does not ask the user to provide a Google password to an AI model. Google connection credentials and the working backup key are protected locally using Windows DPAPI. A separately saved portable recovery key is required to recover encrypted history without the original computer.

Controls, correction and deletion

The owner can pause awareness, exclude folders, stop the camera, clear face enrollment, inspect and correct memories, forget retained facts, export history, and disable backups in AMARA. Exclusions retract indexed excerpts and automatic interpretations from those locations. User-confirmed memories remain separately editable.

Forgetting clears the retained fact and associated evidence from active retrieval. Earlier local or cloud archives may still contain earlier records. The owner controls those files and can remove them separately. Plain history exports contain private information and should be stored accordingly.

Google access can be revoked in Google Account connections. Revocation stops future authorized API access; it does not automatically remove copies already retained on the owner's computer or encrypted archives in their Drive.

Google API policy

AMARA's handling of Google data follows the Google API Services User Data Policy, including its Limited Use requirements. Google data is used only for the personal-assistant purposes explained above.

This information website

These static information pages are hosted on GitHub Pages. They contain no desktop application records, forms, analytics scripts or camera feed. GitHub may process visitor IP addresses for security, as described in its Pages documentation.

Operator and questions

This is an owner-operated personal application, not a public account service. The responsible operator is identified by the support contact shown on its Google authorization screen. Household members should use the owner to review or remove their local profile and enrollment.
